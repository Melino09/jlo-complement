# Complément Excel J-LO (test)

Pages d'un complément Excel : est-ce que le planning J-LO peut s'ouvrir dans Excel au travail ?

- `manifest.xml` : le fichier à mettre dans un dossier partagé et à ajouter dans Excel (Catalogues de compléments approuvés).
- `taskpane.html` : le panneau du test (lecture des onglets, écriture dans un onglet caché « JLO_TEST », réglages du fichier).
- `index.html` : vérifie que le réseau laisse passer ce site, et télécharge `manifest.xml`.

Ce dépôt ne contient que le programme : **jamais de noms, de plannings ni de données**. Les données restent dans le fichier Excel.
